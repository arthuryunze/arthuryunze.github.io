# 使 Google 搜索引擎收录自己的 Github Page 博客

## 登陆 Google 收录地址

https://search.google.com/search-console/welcome

## 手动设置站点地图

选择右边网址前缀选项，填入 github page 地址，然后把生成的 html 文件放到博客 index 同级路径下，发布到 github page，校验一下，需要等待一天左右。
